# Topology Files

This folder contains the visual topology for the VLSM lab.

## Files

- `VLSM_Topology.png` — topology diagram used to build the Packet Tracer lab.
- `VLSM_192.168.5.0_24.pkt` — **add your completed Cisco Packet Tracer project here**.

The `.pkt` file cannot be reconstructed from the screenshot alone because the screenshot does not contain the Packet Tracer project's internal device configuration/state.

After completing the lab in Cisco Packet Tracer, save the project as:

`VLSM_192.168.5.0_24.pkt`

and place it in this `topology/` folder before pushing the repository to GitHub.
